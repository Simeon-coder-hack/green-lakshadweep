An innovative marine renewable energy startup concept and high-fidelity interactive digital platform engineered to eliminate diesel dependence across the **Lakshadweep Archipelago** through marinized offshore wind, ocean wave energy, solar PV, and intelligent battery storage microgrids.

---

## 🌊 Overview & Core Vision

Lakshadweep's pristine coral atolls are among the most fragile marine ecosystems on Earth. Currently, over **88% of the archipelago's electricity relies on High-Speed Diesel (HSD)** transported across 200–440 km of open Arabian Sea from Kochi.

**Green Lakshadweep** introduces a multi-resource hybrid energy architecture that harmonizes:
1. **Offshore Wind Turbines:** Harvesting steady Arabian Sea trade winds and southwest monsoon flows.
2. **Ocean Wave Energy Converters (WEC):** Capturing continuous long-period groundswells (15–20 kW/m on western barrier reefs).
3. **Solar PV & Battery Energy Storage (BESS):** Buffering midday solar peaks and ensuring round-the-clock grid stability.
4. **Smart Energy Management System (EMS):** Sub-second grid-forming inverters and predictive dispatch algorithms.

## 🚀 Key Features

- **Cinematic 3D WebGL Ocean Canvas:** Interactive procedural wave simulation with floating point absorber buoys, rotating marinized wind turbines, and mouse parallax.
- **The Energy Challenge Dossier:** Verified Central Electricity Authority (CEA) and Lakshadweep Electricity Department (LED) data on generation costs (₹28–₹45+/kWh) and 43,500+ tonnes of avoidable CO₂ emissions.
- **Interactive Wind Energy Calculator:** Live parametric calculator with historical government proposal comparisons (3x 250 kW LED study), annual MWh projections, and diesel liters saved.
- **Interactive Wave Energy Calculator:** Converts wave power density (kW/m) and wavefront capture length into theoretical vs actual electrical output.
- **Tidal Energy Hydrokinetic Analysis:** Transparent scientific assessment of lagoon channel velocities without fabricated figures.
- **Animated 5-Tier Hybrid Energy Flow Diagram:** Interactive subsystem telemetry and 24-hour resource complementarity timeline.
- **Live 24-Hour Telemetry Dashboard:** Recharts stacked area visualizations with 4 weather scenarios and an hour-by-hour dispatch scrubber.
- **Geospatial Island Explorer:** Interactive map covering Kavaratti, Agatti, Bangaram, Minicoy, Kadmat, Kalpeni, and Amini.
- **Startup Business Model & LCOE Economics:** The 7 core startup service pillars and a 3-phase commercialization roadmap.
- **Peer-Reviewed Scientific Modal:** Complete formal citations (NIOT, CSIR-NIO, CEA, JERC) and mathematical formulations.

## 💻 Local Development Setup

### Prerequisites
- Node.js (v20.18+ or v22.x)
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/simeon-coder-hack/green-lakshadweep.git

# Navigate into the project directory
cd green-lakshadweep

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be accessible at `http://localhost:5173/`.

### Production Build
```bash
npm run build
```

## 🔬 Scientific Data & Methodology

All baseline figures comply with published peer-reviewed studies and government reports:
- **NIOT (National Institute of Ocean Technology):** Indian Ocean Wave Atlas & Marine Energy Technical Bulletin (10–15 kW/m average, 15–20 kW/m western monsoon swell).
- **CSIR - National Institute of Oceanography:** *Seasonal Variations of Wave Power Characteristics at Kavaratti Island* (Sanil Kumar et al.).
- **Central Electricity Authority (CEA):** *Report on Power Supply Position & Diesel Generation in Lakshadweep Islands*.
- **Solar Energy Corporation of India (SECI):** 1.4 MWp Kavaratti & 1.7 MWp Agatti solar + BESS installations.
